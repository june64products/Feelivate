Drop all files into: **`frontend/public/landing/`**

## Tips
- Screenshots me demo/clean data rakhna (real emails/names nahi).
- Videos ko compress karke dena (HandBrake / ffmpeg) taaki page fast rahe.
- Aspect ratio consistent ho to best (e.g. sab desktop screens ~16:10).
- Jitne assets ready hain utne se main shuru kar dunga — baaki baad me add ho sakte hain.

Files daal dene ke baad bas bata dena "assets ready" — main landing page bana dunga.
